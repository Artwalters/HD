## ⚠️ KRITIEKE GIT INSTRUCTIES - VERPLICHT OM TE VOLGEN ⚠️

### ABSOLUUT VERBODEN - NOOIT DOEN:
- **NOOIT** `git add`, `git commit`, `git push` of andere git commando's uitvoeren zonder EXPLICIETE TOESTEMMING
- **NOOIT** automatisch committen "voor de gebruiker" - ook niet als het "handig" lijkt
- **NOOIT** "even snel pushen" - zelfs niet na het vragen van toestemming voor commits

### VERPLICHTE PROCEDURE:
1. **ALTIJD VRAGEN**: "Wil je dat ik dit commit en push naar GitHub?"
2. **WACHTEN**: Op expliciete bevestiging van de gebruiker
3. **ALLEEN DAN**: Git commando's uitvoeren

### GELDIGE TOESTEMMINGEN:
- ✅ "Ja, commit dit"
- ✅ "Push dit naar GitHub" 
- ✅ "Commit en push dit"
- ✅ "Super push dit nu naar github" (zoals eerder gezegd)

### ONGELDIGE AANNAMES:
- ❌ Code is klaar = automatisch committen
- ❌ Gebruiker lijkt tevreden = automatisch pushen  
- ❌ "Het is logisch om nu te committen"
- ❌ Eerdere toestemming = permanente toestemming

### BIJ TWIJFEL:
- STOP en VRAAG expliciet om toestemming
- Leg uit WAT je wilt committen
- Wacht op duidelijke bevestiging
